# Interview Preparation

## Цільові ролі

- Middle DevOps Engineer.
- Cloud / Infrastructure Engineer.
- Platform Engineer.
- Build & Release Engineer.
- SDET / QA Infrastructure Engineer — лише як стратегічний місток, якщо він наближає до DevOps.

## Принцип

Рівень визначається не загальним стажем у IT, а самостійністю у DevOps-обов'язках. Senior QA досвід — перевага в інженерній зрілості, CI/CD, автоматизації та комунікації, але не заміна практики Linux/cloud/Kubernetes.

## Технічні домени

- [ ] Linux administration.
- [ ] Networking.
- [ ] Bash / Python automation.
- [ ] Docker.
- [ ] CI/CD.
- [ ] AWS.
- [ ] Terraform.
- [ ] Ansible.
- [ ] Kubernetes.
- [ ] Monitoring / alerting.
- [ ] Security.
- [ ] Incident response / troubleshooting.

## STAR приклади

Підготувати реальні приклади з роботи:
- CI pipeline improvement.
- Automation infrastructure.
- Production-like debugging.
- Cross-team incident.
- Reliability improvement.
- Risk reduction.

Не приписувати собі production ownership, якщо його не було.
