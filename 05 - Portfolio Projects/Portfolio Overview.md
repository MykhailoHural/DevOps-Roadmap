# Portfolio Projects

Мета — показати здатність будувати, підтримувати, діагностувати та відновлювати інфраструктуру. Не роби проєкти заради кількості технологій.

## Project 1 — Infrastructure & Automation

**Стек:** Linux, Docker, Bash, Python, Nginx, PostgreSQL, Ansible.

Deliverables:
- [ ] Architecture diagram.
- [ ] Deployment from scratch.
- [ ] Ansible configuration.
- [ ] Backup/restore.
- [ ] Health checks.
- [ ] Troubleshooting scenarios.
- [ ] README and cleanup instructions.

## Project 2 — Cloud Infrastructure

**Стек:** AWS, Terraform, IAM, VPC, EC2, S3, Load Balancer, CI/CD.

Deliverables:
- [ ] Architecture diagram.
- [ ] Terraform modules.
- [ ] IAM least privilege.

- [ ] CI/CD deployment.

## Project 3 — Production-like DevOps Platform

**Стек:** Kubernetes, Helm, ArgoCD, Prometheus, Grafana, DevSecOps.

Deliverables:

## Якість портфоліо

Кожен проєкт має містити не лише happy path, а й задокументовану поломку, діагностику, root cause та виправлення.
