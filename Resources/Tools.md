# Tools

## Local workstation

- Ubuntu 24.04.
- Git.
- VS Code or preferred editor.
- Obsidian.
- Docker Engine / Docker Compose.
- Python 3.
- `curl`, `dig`, `ip`, `ss`, `tcpdump`, `openssl`, `nc`.

## Optional later

- kind / minikube.
- kubectl.
- Helm.
- Terraform.
- Ansible.
- AWS CLI.
- Prometheus.
- Grafana.
- Argo CD CLI.

## Safety

Не запускай destructive commands на робочих системах або production. Для лабораторних використовуй локальні ізольовані середовища.
