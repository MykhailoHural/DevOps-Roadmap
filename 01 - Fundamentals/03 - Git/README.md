# Git & Software Development Fundamentals

**Тривалість:** 2 тижнів  
**Статус:** Not started

## Мета

Core: Git objects, working tree/index, branches, merge/rebase, revert/reset, conflicts, reflog, remotes and SSH. Practical: recover mistaken changes, resolve conflicts, use a team workflow. Optional: advanced hooks and internals.

## Глибина

- **Core:** обов'язковий фундамент.
- **Practical:** самостійне виконання лабораторних.
- **Advanced / Optional:** відкласти, якщо не потрібне для цільової вакансії.

## Troubleshooting

Обов'язково створити щонайменше один сценарій із навмисно зламаною конфігурацією. Записати симптоми, гіпотезу, команди діагностики, root cause, resolution та prevention.

## Gate
