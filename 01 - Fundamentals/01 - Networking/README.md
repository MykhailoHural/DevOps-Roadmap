# Module 01 — Networking Fundamentals

**Тривалість:** 3 тижні · **15–21 година** · **Ubuntu 24.04**

## Мета

Зрозуміти шлях запиту від клієнта до сервера та навчитися локалізувати проблеми DNS, TCP, routing, TLS та HTTP.

## Результати

- Пояснювати OSI та TCP/IP.
- Розуміти IPv4, CIDR, subnetting, MAC, ARP, routing.
- Розуміти TCP, UDP, ports, sockets.
- Пояснювати DNS, DHCP, NAT.
- Розуміти HTTP/HTTPS та TLS.
- Використовувати `ip`, `ss`, `ping`, `dig`, `curl`, `nc`, `tcpdump`, `openssl`.
- Розрізняти NXDOMAIN, connection refused та timeout.
- Діагностувати базову мережеву проблему без готового рецепта.
