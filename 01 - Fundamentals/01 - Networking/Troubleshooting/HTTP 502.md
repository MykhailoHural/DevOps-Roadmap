# Scenario — HTTP 502 Bad Gateway

## Симптом
Reverse proxy повертає 502.

## Що перевірити
- Чи працює reverse proxy.
- Чи доступний upstream.
- Чи правильні upstream host та port.
- Чи може proxy встановити TCP connection.
- Логи proxy та application.

## Важливо
502 не означає автоматично, що проблема саме в DNS. Потрібно перевіряти upstream і контекст помилки.
