# Lab 05 — Trace an HTTP Request

## Команда

```bash
curl -v https://example.com
```

## Завдання

Знайди у verbose output:

- [ ] DNS resolution / resolved address.
- [ ] TCP connection.
- [ ] TLS negotiation.
- [ ] Certificate information.
- [ ] HTTP request line.
- [ ] HTTP response status.
- [ ] Response headers.

## Поясни послідовність

1. Який етап виконується першим?
2. Чому потрібен DNS?
3. Коли встановлюється TCP connection?
4. Для чого TLS?
5. На якому етапі починається HTTP?
