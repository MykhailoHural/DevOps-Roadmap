# Lab 01 — Understand Your Network

## Мета
Зібрати інформацію про активну мережеву конфігурацію Ubuntu.

## Команди

```bash
ip -br addr
ip route
ip neigh
ip route get 1.1.1.1
```

## Завдання

- [ ] Знайти активний interface.
- [ ] Записати локальну IPv4-адресу.
- [ ] Записати prefix length.
- [ ] Знайти default gateway.
- [ ] Знайти MAC address.
- [ ] Переглянути neighbor table.
- [ ] Пояснити маршрут до `1.1.1.1`.
