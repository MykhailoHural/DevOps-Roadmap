# Week 01 — Network Fundamentals, IP & Routing

**Час:** 5–7 годин

## Теорія

- OSI та TCP/IP models.
- Encapsulation / decapsulation.
- IPv4, public/private IP.
- Subnet mask, CIDR.
- MAC, ARP.
- Switch vs router.
- Default gateway.
- Routing table.

1. Переглянути вступне відео TechWorld with Nana.
2. Пройти відповідні розділи Easy Tech про Ethernet, IPv4, ARP та routing.
3. Виконати Lab 01.
4. Виконати Lab 02.
5. Пояснити маршрут до зовнішньої IP-адреси.

## Команди

```bash
ip -br addr
ip route
ip neigh
ip route get 1.1.1.1
ping -c 4 1.1.1.1
```
