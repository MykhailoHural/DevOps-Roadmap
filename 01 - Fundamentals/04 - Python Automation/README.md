# Python for Infrastructure Automation

**Тривалість:** 3 тижнів  
**Статус:** Not started

## Мета

Core: syntax, types, collections, functions, modules, exceptions, venv, pip, files, subprocess, logging, JSON/YAML, HTTP APIs. Practical: health checker, API automation, log parser, backup utility with tests. Optional: advanced asyncio and packaging.

## Глибина

- **Core:** обов'язковий фундамент.
- **Practical:** самостійне виконання лабораторних.
- **Advanced / Optional:** відкласти, якщо не потрібне для цільової вакансії.
