# Linux Administration & Bash

**Тривалість:** 5 тижнів  
**Статус:** Not started

## Мета

Core: Linux filesystem, users/groups, permissions, processes, systemd, SSH, logs, disks, CPU/RAM, Bash fundamentals. Practical: create service, manage users, diagnose resource and service failures, automate backup. Optional: advanced kernel internals and complex shell tooling.

## Глибина

- **Core:** обов'язковий фундамент.
- **Practical:** самостійне виконання лабораторних.
- **Advanced / Optional:** відкласти, якщо не потрібне для цільової вакансії.
