# Full DevOps Engineer Roadmap

Навчальний Obsidian Vault для переходу із Senior General QA у DevOps із цільовим рівнем Middle.

- **Тривалість:** 57 тижнів
- **Навантаження:** 5–7 год/тиждень
- **Орієнтовний обсяг:** 285–399 годин
- **Основне середовище:** Ubuntu 24.04
- **Cloud:** AWS
- **CI/CD:** GitHub Actions
- **IaC:** Terraform
- **Containers:** Docker + Kubernetes
- **Observability:** Prometheus + Grafana

## Як відкрити

1. Розпакуй архів.
2. В Obsidian обери **Open folder as vault**.
3. Вкажи папку `DevOps-Roadmap`.
4. Почни з [[00 - Dashboard/Home]].

## Принципи

- Core — обов'язковий фундамент.
- Practical — те, що потрібно вміти робити самостійно.
- Advanced / Optional — можна відкласти до появи відповідних задач.
- Кожен модуль має практичний gate.
- Troubleshooting є наскрізною практикою.
- Аналіз вакансій починається з першого тижня.
- Не потрібно проходити платні курси або купувати сертифікації, щоб почати.

## Обережність із витратами

Локальні лабораторні — пріоритет. Для AWS використовуй бюджетні обмеження, billing alerts та cleanup checklist. Не залишай ресурси працювати після лабораторної. Безкоштовний tier не означає гарантовано нульову вартість.

## Статус проєкту

Це навчальний vault із повністю деталізованим Module 01 та структурою решти roadmap. Посилання на ресурси потрібно перевіряти перед використанням; доступність курсів і умови безкоштовного доступу можуть змінюватися.
