# GitOps & DevSecOps

**Тривалість:** 4 тижнів  
**Статус:** Not started

## Мета

Core: GitOps, desired state, reconciliation, Argo CD, sync/health/drift/rollback, secrets, least privilege, image/dependency scanning, Trivy, SBOM, supply-chain basics, Kubernetes hardening. Practical: GitOps deployment with security checks. Optional: advanced OPA/SLSA implementation.

## Глибина

- **Core:** обов'язковий фундамент.
- **Practical:** самостійне виконання лабораторних.
- **Advanced / Optional:** відкласти, якщо не потрібне для цільової вакансії.
