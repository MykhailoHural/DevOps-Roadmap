# SRE, Production Operations & Capstone

**Тривалість:** 5 тижнів  
**Статус:** Not started

## Мета

Core: SLI/SLO, error budgets, incidents, RCA, postmortems, capacity, HA, backup/DR, rollback, cost optimization, runbooks. Practical: production incident simulation and final capstone. Optional: advanced chaos engineering.

## Глибина

- **Core:** обов'язковий фундамент.
- **Practical:** самостійне виконання лабораторних.
- **Advanced / Optional:** відкласти, якщо не потрібне для цільової вакансії.

## Troubleshooting

Обов'язково створити щонайменше один сценарій із навмисно зламаною конфігурацією. Записати симптоми, гіпотезу, команди діагностики, root cause, resolution та prevention.
