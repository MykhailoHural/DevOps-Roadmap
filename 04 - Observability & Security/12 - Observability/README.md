# Monitoring, Logging & Observability

**Тривалість:** 4 тижнів  
**Статус:** Not started

## Мета

Core: metrics/logs/traces concepts, SLI/SLO/SLA, RED/USE, Prometheus, exporters, PromQL, Grafana dashboards and alerting. Practical: monitor Linux/containerized app and diagnose latency. Optional later: Loki, OpenTelemetry, Jaeger.

## Глибина

- **Core:** обов'язковий фундамент.
- **Practical:** самостійне виконання лабораторних.
- **Advanced / Optional:** відкласти, якщо не потрібне для цільової вакансії.
