# Lab Budget & Cost Control

## Default rule

Спочатку локальні лабораторні. Не створюй cloud resources, якщо ту саму концепцію можна безкоштовно відпрацювати локально.

## AWS safety checklist

- [ ] Увімкнути billing alerts / budget.
- [ ] Перевірити актуальні ціни в регіоні до створення ресурсів.
- [ ] Не покладатися на Free Tier як на гарантію нульової вартості.
- [ ] Не залишати EC2, NAT Gateway, Load Balancer, EBS та інші платні ресурси після лабораторної.
- [ ] Перевіряти ресурси в усіх регіонах.
- [ ] Видаляти ресурси після виконання.
- [ ] Перевіряти залишкові snapshots, volumes, elastic IPs та logs.
- [ ] Перевіряти Billing dashboard після лабораторної.

## Paid learning

- KodeKloud: платна підписка може бути корисною, але не обов'язкова.
- Сертифікації: не купувати, поки аналіз вакансій не покаже, що вони мають конкретну цінність.
- Не купувати кілька курсів на одну тему.
