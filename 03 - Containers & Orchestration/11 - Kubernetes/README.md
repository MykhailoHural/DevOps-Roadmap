# Kubernetes & Helm

**Тривалість:** 7 тижнів  
**Статус:** Not started

## Мета

Core: architecture, Pods, Deployments, Services, DNS, Ingress, ConfigMaps, Secrets, PV/PVC, probes, requests/limits, scheduling, Helm, RBAC, security contexts and troubleshooting. Practical: deploy and diagnose a multi-service application. Optional: Gateway API depth, operators, advanced CNI and service mesh.

## Глибина

- **Core:** обов'язковий фундамент.
- **Practical:** самостійне виконання лабораторних.
- **Advanced / Optional:** відкласти, якщо не потрібне для цільової вакансії.
