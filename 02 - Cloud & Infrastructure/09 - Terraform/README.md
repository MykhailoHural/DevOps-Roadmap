# Terraform & Infrastructure as Code

**Тривалість:** 4 тижнів

## Мета

Core: providers, resources, variables, outputs, locals, modules, dependencies, state, remote backend, locking, plan/apply/destroy, import, drift. Practical: provision AWS infrastructure using reusable modules. Optional: advanced testing and policy frameworks.

## Глибина

- **Core:** обов'язковий фундамент.
- **Practical:** самостійне виконання лабораторних.
- **Advanced / Optional:** відкласти, якщо не потрібне для цільової вакансії.
