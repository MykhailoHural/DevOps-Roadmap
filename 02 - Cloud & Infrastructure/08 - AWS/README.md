# AWS Cloud Engineering

**Тривалість:** 5 тижнів

## Мета

Core: regions/AZ, IAM, VPC, subnets, route tables, IGW/NAT, SG/NACL, EC2, EBS, S3, ALB, Auto Scaling, RDS, CloudWatch, CLI, billing. Practical: small secure environment. Optional: broad survey of Azure/GCP.

## Глибина

- **Core:** обов'язковий фундамент.
- **Practical:** самостійне виконання лабораторних.
- **Advanced / Optional:** відкласти, якщо не потрібне для цільової вакансії.
