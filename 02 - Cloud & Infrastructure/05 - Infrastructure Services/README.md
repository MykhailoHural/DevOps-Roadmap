# Web Servers, Databases & Infrastructure Services

**Тривалість:** 4 тижнів  
**Статус:** Not started

## Мета

Core: Nginx, reverse proxy, upstreams, TLS termination, PostgreSQL roles/connections/backup/restore. Practical: deploy app + DB behind Nginx and diagnose failures. Redis and RabbitMQ: architecture overview, basic operations and diagnostics only.

## Глибина

- **Core:** обов'язковий фундамент.
- **Practical:** самостійне виконання лабораторних.
- **Advanced / Optional:** відкласти, якщо не потрібне для цільової вакансії.
